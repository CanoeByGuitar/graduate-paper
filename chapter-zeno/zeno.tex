\chapter{非连续速度场物质点法的GPU优化算法}
为了进一步提高高精度流固耦合场景下物质点法的计算效率，本章为基于DC-APIC积分器的非连续速度场设计了GPU优化方案。本章首先回顾了GPU物质点法的主要流程和重要数据结构GSPGrid，其中重点介绍了基于线程数规约的P2G算法；然后基于这种基于线程数规约的算法，提出了面向非连续数据的线程束写入优化算法，以适应本文第二章中根据兼容性控制粒子传输方式的算法；最后通过两个百万粒子级别的高分辨率场景，对基于CPU的DC-APIC物质点法和其GPU优化版本进行对比，实验结果有效地验证了本章非连续速度场物质点法的GPU优化算法的高效性。

\section{GPU物质点法算法流程}
GPU物质点法底层使用GSPGrid数据结构~\cite{gpumpm},它是SPGrid~\cite{setaluri2014spgrid}的GPU优化版本，其结构如图~\ref{fig:gspgrid}所示。整个模拟区域的背景网格被拆分成4$\times$4$\times$4(二维下为4$\times$4)的GSPGrid块（图中深蓝色区域）,若粒子$p$的插值基点为$base$,则把该粒子数据存储在$base$向xyz轴(二维下为xy轴)偏移$\Delta x$的网格单元内。如图~\ref{fig:gspgrid}左上侧子图所示，对于一个2$\times$2的网格，将左下格点作为插值基点的所有粒子分布在黄色区域内。因此存储在同一GSPGrid块内的粒子应当分布在橙色区域中，这个区域称为对偶块。所有的粒子网格传输操作(P2G和G2P)都在同一局部GSPGrid块内规约进行。为每个粒子分配一个CUDA线程进行并行计算，为避免读写冲突，需要对粒子进行排序，排序后同一对偶块内的粒子会交替地在不同线程进行规约计算。但是对于高精度仿真场景，一个GSPGrid块内的粒子数量是多于CUDA块数量的，GSPGrid额外增加一个虚拟地址到物理地址到页表映射，让一个GSPGrid对应一个或多个CUDA块。部分粒子会处在两个GSPGrid块的交界处，例如图~\ref{fig:gspgrid}中的绿色粒子，在G2P和P2G阶段该粒子和周围9个格点发生数据交换，其中蓝色格点在本地GSPGrid块上，而红色节点需要访问邻居块，因此需要使用GPU共享内存，存储周围7个邻居块的数据(二维下是3个)。

在粒子到网格传输(P2G)过程中,并行计算会导致多个粒子同时写入同一格点造成写冲突，为实现安全写操作通常有收集(Gather)和散播(Scatter)两种方式,如图~\ref{fig:gather}所示，前者在每一个时间步收集每个格点影响范围内的粒子$id$形成一个队列，每次并行计算所有队列同一位置的粒子对网格贡献；后者直接使用原子操作并行写入。图中实线箭头表示按序同步执行，虚线箭头表示异步执行原子操作。

    \centering
    \includegraphics[width=0.8\linewidth]{fig/gather.png}
    \caption{并行粒子网格传输的收集和散播示意图}
    \label{fig:gather}
\end{figure}

Gao等提出的散播优化算法~\cite{gpumpm}如图~\ref{fig:warp}所示，在一个线程束内，几组粒子需要分别将其属性添加到相应的格点上。对于特定组的粒子（例如，粒子2-5），传统方法会通过原子操作来同时对同一位置执行写入操作，我们利用线程束级别的CUDA内置函数，即ballot和shfl来解决这一问题。首先，为每组选择一个代表粒子（即边界标记被置位1的粒子）。然后，通过从右向左迭代式的洗牌(shfl)操作，将同一组内其他所有粒子的属性累加到代表粒子上。每次迭代后，洗牌的步长加倍。最后，由代表粒子负责将累加结果写入目标格点。通过这种方式，所有线程束规模的写入冲突都得以消除。为了进一步减少不同线程束之间的全局写入冲突，共享内存充当缓冲区，用于临时存储不同线程束的求和结果。共享内存的写入必须使用原子操作，但在实验中这种跨线程束的冲突很少发生，因此带来的额外开销可以忽略不计。

\section{面向非连续数据的线程束写入优化算法}
对于大多数常见的串行数据，如速度和应力，使用包含CUDA原语的传统线程束写入算法可以轻松完成求和操作。然而，在本文第三章提出的基于非连续速度场的物质点法中，格点的固体质量需要根据该格点周围受B样条插值函数影响的固体粒子来计算。区分固体粒子和流体粒子的最佳方法是在采样时为它们分配一个标签。因此，我们创新地提出面向非连续数据的线程束写入优化算法，以适应新的属性。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\linewidth]{figures/warp_write.png}
    \caption{归约非连续数据的方法和跨线程束写入冲突解决方案}
    \label{fig:reduce}
\end{figure}

图\ref{fig:reduce}展示了这一过程的工作原理。首先进行线程束计算算法，通过CUDA线程束内置函数ballot计算每个粒子的边界标记和间隔，当线程束计算算法完成后，由同一个线程管理的多个粒子将知晓自己是否是当前线程束中的第一个粒子，以及还剩下多少个粒子。然后对每组粒子进行从右向左的洗牌(shfl)操作，由于本文使用DC-APIC积分器来实现非连续的流固耦合速度场，在某一些核函数内，粒子网格传输会忽略部分粒子的影响，例如在计算格点固体质量时，会忽略流体粒子的影响；在G2P和P2G过程中，受兼容性影响，部分粒子的质量和动量也不会全部传递到周围格点，所以这一步的洗牌操作会根据粒子标签有选择的进行，例如图中的$m_4^f$和$m_6^f$没有传递给下一次迭代。算法~\ref{alg:gpu1}给出了计算固体网格质量的线程束写入算法。

\begin{algorithm}
    \caption{计算固体网格质量的非连续数据的线程束写入算法}
    \label{alg:gpu1}
    \DontPrintSemicolon
    \KwIn{$T* buffer$, $T$ mass, $int$ tag, $int$ iter}
    \Begin{
        $stride \gets 1$\;
        $kind \gets tag$ \tcp*[r]{1 代表固体，0 代表流体}
        
        \eIf{$kind$}{
            $val \gets mass$ \tcp*[r]{仅对固体粒子的质量进行规约}
        }{
            $val \gets 0$
        }
        
        \While{$stride \leq iter$}{
            $tmp \gets \textbf{shfldown}(val, stride)$\;
            \If{$stride \leq interval$}{
                $val \gets val + tmp$
            }
            $stride \gets stride \ll 1$\;
        }
        
        \If{boundary}{
            $*buffer \gets *buffer + val$
        }
    }
    \end{algorithm}
    
由于每一时间步都会更新粒子位置，GSPGrid数据结构也需要在每一时间步随之更新，因此粒子需要被重新排序，然而对于高分辨率模拟而言，重新排序本身可能会成为瓶颈。这是因为每个粒子都携带着诸如位置、速度和形变梯度等多种属性，以非合并的方式读写这些数据会非常耗时，因此基本的粒子属性根据其内在特性有着不同的重排序方案。由于粒子的质量在仿真过程中是恒定的，所以设定质量顺序保持不变，针对本文提出的DC-APIC积分器带来的额外粒子属性，流固相场值$s_p$同质量一样在仿真过程中不会改变，因此无需重新排序。对于速度属性，在每次G2P之后速度都会进行更新，相当于在每个时间步的最后对其进行重新排序，因此需要维护一个从当前顺序到先前顺序的映射关系。DC-APIC积分器所需的粒子法线也类似于速度的重排方式。

\section{本章小节}
本章针对高精度流固耦合场景下物质点法的计算效率优化，提出了一种面向非连续速度场的GPU加速方案。首先，我们回顾了GPU物质点法的核心流程与关键数据结构GSPGrid，重点介绍了采用线程数规约策略的P2G算法。基于此，我们进一步设计了一种针对非连续数据的线程束写入优化算法，以适应第二章中提出的基于兼容性控制的粒子传输方法。最后，我们通过在两个高分辨率场景下，对比基于SIMD加速的CPU版本DC-APIC物质点法与其GPU优化版本，实验结果充分验证了所提出优化方案的高效性。
